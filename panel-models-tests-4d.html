F test for unit effects
pooled vs fixed		F = [(SSEpooled − SSEFE) ÷ (N − 1)] ÷ [SSEFE ÷ (NT − N − K)]Pooled OLS assumes every unit has the same intercept. This test checks that before you trust it: if units differ, ignoring it biases β.Why: do units differ in level?
H₀: all ai equal. p < 0.05 → reject → fixed effects. p ≥ 0.05 → pooled is fine.		Reject → fixed effects: units have their own levels, and leaving them in the error biases β.
Keep H₀ → pooled OLS: simpler, nothing lost.		Stataxtreg y x, fe"F test that all u_i=0" at the bottomPythonres_fe.f_pooled
Breusch-Pagan LM
pooled vs random		LM = NT ÷ [2(T − 1)] × [Σi(Σtêit)² ÷ ΣΣêit² − 1]² ~ χ²(1)Checks whether the error has a part shared by all rows of one unit. If it does, pooled OLS treats related rows as independent and its SEs are wrong.Why: is there a random unit effect?
H₀: σu² = 0. p < 0.05 → reject → random effects. p ≥ 0.05 → pooled is fine.		Reject → random effects (not pooled): the rows of one unit share an error part, so pooled OLS treats them as independent and its SEs are wrong.
Keep H₀ → pooled OLS.		Stataxtreg y x, re

Hausman
random vs fixed		H = (bFE − bRE)′[VFE − VRE]⁻¹(bFE − bRE) ~ χ²(k)Random effects is more precise but only valid if ai is unrelated to x. Fixed effects is always valid, so comparing the two reveals whether RE is safe.Why: is ai tied to x?
H₀: RE is consistent. p < 0.05 → reject → fixed effects. p ≥ 0.05 → random effects.
If H is negative or SEs are clustered, use the robust (Mundlak) form.		Reject → fixed effects: RE would be biased because ai moves with x.

Wooldridge
serial correlation		regress Δêit on Δêi,t−1; H₀: coefficient = −0.5 ~ F(1, N − 1)Usual SEs assume errors are independent over time. Panel data often has streaks, so this test checks before you trust the p-values.Why: errors that follow each other make SEs too small.
H₀: no serial correlation. p < 0.05 → problem → cluster SE by unit or add lags.		Reject → cluster SE by unit (or add lagged y): errors that follow each other make usual SEs too small and p-values too optimistic.
